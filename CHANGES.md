# Изменения в llm-speed-benchmark

## bench_single.py — исправления багов

### 1. Не загружал `.env`
- **Проблема:** `load_dotenv()` не вызывался, все настройки из `.env` игнорировались
- **Исправление:** Добавлен `load_dotenv()` в начало файла после импортов

### 2. Отсутствовал `argparse` и `--duration`
- **Проблема:** Документация обещала `--duration 60`, но argparse отсутствовал
- **Исправление:** Добавлен `argparse` с `--duration` (секунды), проверка таймаута в цикле

### 3. `duration=0` → бесконечный цикл
- **Проблема:** `if duration:` пропускал `0` как falsy → бесконечный цикл
- **Исправление:** `if duration is not None:` вместо `if duration:`

### 4. `TOKEN_LIMIT_WARN` не обновлялся при изменении `MAX_CONTEXT_TOKENS`
- **Проблема:** Константа вычислялась один раз при импорте
- **Исправление:** Вынес в функцию `_token_limit_warn()` с динамическим расчётом

### 5. `truncate_history()` удалял все пары
- **Проблема:** `while len(result) > 2` удалял всё до system, оставляя 0 пар
- **Исправление:** `while len(result) > 3` — оставляет system + 1 пара user/assistant

### 6. Хардкодная скорость `300 tok/s`
- **Проблема:** Пока `usage` не пришёл (финальный чанк), показывал `300` — выдуманную цифру
- **Исправление:** Счётчик `chunk_count` (1 чанк ≈ 1 токен) для реального времени; fallback на `chunk_count` вместо `int(elapsed * 300)`

### 7. Пустой ответ → бесконечный цикл
- **Проблема:** `completion_tokens=0` не добавлял токены в контекст → цикл не выходил
- **Исправление:** `if completion_tokens == 0: continue` с предупреждением

### 8. `.venv` — старый путь
- **Проблема:** `~/venvs/...` не находил венв после переезда
- **Исправление:** Абсолютный путь `/home/hermes/workspace/venvs/llm-speed-benchmark/venv/`

## bench_single.py — новые метрики

### 9. TTFT (Time To First Token)
- Измеряет время от отправки запроса до получения первого токена
- В live-строке: `TTFT 11.65s`
- В итогах: `Avg TTFT: 11.65s`

### 10. Мгновенная скорость (instant speed)
- Считается по последним `INSTANT_WINDOW` токенам (окно скользящее)
- Константа `INSTANT_WINDOW = 200` (можно менять)
- В live-строке: `36 inst t/s`

### 11. Формат live-строки
```
Было: ⏱ 963 tok | 300 tok/s
Стало: ⏱ 963 tok | 25 avg t/s | 36 inst t/s | TTFT 11.65s
```

### 12. Формат статичной строки
```
Было: Call   2 | ... | Last 14.8 | Avg 22.8 tok/s
Стало: Call   2 | ... | Speed 14.8 t/s | Avg 22.8 t/s | TTFT 11.65s
```
- `Last` → `Speed` (скорость в последнем вызове)
- `tok/s` → `t/s` (компактнее)
- Добавлен `TTFT`

### 13. Формат итогов
```
Добавлено: Avg TTFT: 11.65s
```
