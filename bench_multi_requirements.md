# Требования к bench_multi.py

## Описание
Многопоточный бенчмарк скорости vLLM. Запускает N независимых процессов (`multiprocessing`), каждый из которых работает аналогично `bench_single.py`, но с уникальным ID потока.

## Параметры командной строки
- `--workers`, `-w` — количество workers (по умолчанию: 4, от 1 до бесконечности)
- `--duration`, `-d` — длительность в минутах (по умолчанию: 5)
- `--max-context` — переопределение MAX_CONTEXT_TOKENS

## Поведение workers

### Уникальные промпты
- Каждый worker имеет уникальный ID: `Поток 0000000N`
- Первый запрос: `Поток 0000000N. Что ты умеешь? Расскажи обо всём максимально подробно.`
- Последующие: `Поток 0000000N (раунд M) продолжай`
- Это создаёт разный KV-кэш для каждого worker

### Жизненный цикл worker
1. Запускается одновременно со всеми другими workers
2. Делает запросы к LLM по очереди (раунд за раундом)
3. Когда cumulative токены >= MAX_CONTEXT_TOKENS:
   - **Не прерывается**
   - Очищает историю (оставляет system)
   - Начинает новый раунд с новым уникальным промптом
4. Работает заданное количество минут или до Ctrl+C

### Независимый подсчёт
- Каждый worker считает свою статистику в отдельном процессе
- Результаты собираются через `multiprocessing.Queue`
- Основной процесс отображает сводную таблицу

## Вывод в консоль

### Таблица обновляется в реальном времени (~1 раз в секунду)

Колонки:
| Колонка | Описание |
|---------|----------|
| ID | Номер worker (0-N) |
| Round | Текущий раунд/круг |
| Prompt | Cumulative prompt tokens |
| Gen | Cumulative completion tokens |
| Total | Сумма prompt + gen |
| Turn | Скорость текущего хода (tok/s) |
| Avg | Средняя скорость за всё время (tok/s) |
| Status | 🔴 streaming / 🟢 completed / ❌ error / ⏳ pending |
| Response | Последние 40 символов текущего ответа |

### Финальные итоги
После завершения или Ctrl+C:
- Статистика по каждому worker (раунды, токены, скорость)
- Общая сумма по всем workers

## Архитектура
```
┌─────────────────────────────────────────────────┐
│                   Main Process                   │
│  ┌───────────────────────────────────────────┐  │
│  │           display_loop()                   │  │
│  │  reads from Queue → draws table (~1Hz)    │  │
│  └───────────────────────────────────────────┘  │
└──────┬──────────────────────────────────────────┘
       │ multiprocessing.Queue
       │
┌──────┼──────────┬───────────┬──────────┐
│      │          │           │          │
▼      ▼          ▼           ▼          ▼
Worker  Worker   Worker ...  Worker    Worker
  0       1        N-2        N-1
```

## Отличия от bench_single.py
1. `multiprocessing` вместо одного процесса
2. `--workers` и `--duration` параметры CLI
3. Уникальные промпты с ID потока
4. При достижении MAX_CONTEXT_TOKENS — новый раунд, не остановка
5. Таблица с N строками обновляется в реальном времени
6. Text ответа виден (N символов последнего чанка)
